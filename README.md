# Library Management System (Java)

A command-line library management system with Java.

## How to Run the Project

1. **Download the Project**:
   - Click the `Code` button (green) in the GitHub repository.
   - Select `Download ZIP` and extract the files.

2. **Prerequisites**:
   - Install [Java JDK](https://www.oracle.com/java/technologies/javase-downloads.html) (JDK 8 or later).
   - Ensure Java is added to your `PATH` (check with `java -version`).

3. **Run the Program**:
   - Open **Command Prompt** (Windows) or **Terminal** (Mac/Linux).
   - Navigate to the **parent folder** of `libraryApp` (the folder containing `libraryApp`):
     ```bash
     cd path/to/parent_folder
     ```
   - Compile and run:
     ```bash
     javac libraryApp/*.java    # Compiles all Java files
     java libraryApp.Main       # Runs the program
     ```
